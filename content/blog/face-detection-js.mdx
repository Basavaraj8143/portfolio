# It Started with Curiosity

While working on my Viklang Banking project, I became interested in exploring face detection. Nobody had specifically asked me to implement it, but I wanted to understand how it could work in my project.

## Exploring JavaScript Models

While researching, I came across JavaScript model files for face detection and recognition. I used those files in my project instead of going with a Python-based approach.

The files included face detection and facial landmark models. I don't remember the exact library I found, but I still have the model files from that experiment.

## What I Learned

This experience reminded me that project work doesn't always have to stop at the assigned requirements. Sometimes, curiosity leads you to explore a technology and try something new.

Even when I don't remember every technical detail today, the experience of exploring and experimenting was valuable in itself.
