# Where It Started

I didn't start learning Java with a perfect roadmap or a clear idea of everything I needed to know.

My motivation came when my teammates chose a Distributed Storage System project. It made me realize that I needed to learn Java, so I decided to get started.

## Learning Through a Project

Alongside learning Java, I started building a URL Shortener using Java and Spring Boot.

I was figuring things out as I went, learning concepts and applying them to the project instead of waiting until I felt completely ready.

I didn't know everything from the beginning. I just kept moving forward, learning and building along the way.

## From C++ to Java

Until then, I had been practising Data Structures and Algorithms in C++. As I became more interested in Java, I decided to switch my DSA practice to Java too.

That change made Java more than just a language I needed for a project. It became a language I wanted to explore further.

## Keeping Things Moving

I continued working on my projects while learning. Rather than treating learning and building as separate activities, I kept doing both.

The more I explored Java and backend development, the more interested I became in understanding how things worked.

## Still Learning

This isn't a story about mastering Java overnight. It's about starting somewhere, finding a reason to learn, and gradually developing an interest in the process.

I'm still learning, still building, and still figuring things out.

This is one part of that journey.
